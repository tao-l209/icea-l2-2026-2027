# README — Projet ICEA L2 Structure de Données

## 📋 Description
Projet académique (L2) portant sur la **structure de données**, développé en **PHP 8.2.12** et utilisant la base de données **`icea-l2-structure-donnees`**.

---

## 🖥️ Environnement

| Composant | Version / Valeur |
|-----------|------------------|
| Système d'exploitation | Windows 11 |
| PHP | 8.2.12 |
| Base de données | `icea-l2-structure-donnees` |

---

## ✅ Prérequis

- **PHP 8.2.12** installé et accessible depuis le terminal (`php -v`)
- **MySQL** ou **MariaDB** (serveur de base de données)
- Extensions PHP activées dans `php.ini` :
  - `pdo_mysql`
  - `mysqli`
  - `mbstring`
  - `openssl`
- Un terminal (PowerShell, CMD ou Git Bash)
